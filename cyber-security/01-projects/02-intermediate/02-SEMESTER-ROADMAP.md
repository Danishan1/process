# Six-Month Recommended Roadmap

| Month | Core concepts | Primary build | Supporting work | Career milestone |
|---|---|---|---|---|
| 1 | Networking, Linux, Wireshark, Python basics | 08 — Recon Framework | Isolated home lab | Set up GitHub and documentation |
| 2 | Linux permissions, Windows basics, testing | 09 — Linux Auditor | 05 — Packet/IDS analysis | Publish first technical write-up |
| 3 | HTTP, sessions, SQL, Burp Suite | 03 — Web Security Platform | 07 — API security tests | First two polished projects; start outreach |
| 4 | VAPT process, evidence, reporting | 01 — VAPT Reporting Platform | Reuse 08 and 03 outputs | Apply to relevant internships |
| 5 | Event logs, SIEM, detection | 04 — Mini SOC | Detection rules and reports | Interview practice |
| 6 | Windows identity, AD, GPO, telemetry | 02 — Active Directory Lab | Integrate with SOC | Refine portfolio and continue applications |

## Weekly split
- 40% fundamentals and revision
- 25% guided hands-on labs
- 25% project implementation
- 10% documentation, GitHub, and applications

## Minimum viable internship portfolio
- Two completed projects with clear tests and reproducible setup
- One flagship project with security findings, fixes, and limitations
- A one-page resume linking the best repositories
- A concise demonstration video or screenshots for each featured project

## Workload caution
Completing all 20 to intermediate depth in six months is unrealistic alongside college for most beginners. Treat this as a multi-semester backlog; prioritize 3–6 exceptional projects over 20 shallow ones.
