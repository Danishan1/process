# Cybersecurity Internship Project Blueprint

A Markdown-first organized collection of **20 intermediate cybersecurity project specifications** aligned to a first-semester syllabus and an internship-oriented portfolio.

## Start here

1. [Master list of all 20 projects](01-PROJECT-MASTER-LIST.md)
2. [Six-month build roadmap](02-SEMESTER-ROADMAP.md)
3. [Portfolio and assessment standard](03-PORTFOLIO-STANDARDS.md)
4. [Lab safety and ethical boundaries](04-LAB-SAFETY.md)
5. [Reusable project template](05-PROJECT-TEMPLATE.md)
6. [Detailed specifications](projects/)

Each project file includes the problem, why it matters, proposed solution, concepts, prerequisite revision, stack, MVP requirements, architecture, phases, real-world scenarios, extensions, testing, safety, portfolio deliverables, interview questions, and definition of done.

**Important:** This is a project planning package, not a set of finished tools. All security testing must be authorized and safely scoped.
