# Cybersecurity Project Bank

### 1. Networking 🔴

#### Beginner

1. **Virtual Network Lab**

   * Build a small network with Linux + Windows VMs
   * IP addressing, subnetting, routing, DNS, DHCP

2. **Network Traffic Analysis Lab**

   * Capture ARP, DNS, TCP, UDP, ICMP, HTTP/HTTPS traffic
   * Analyze packets using Wireshark

3. **Subnetting & Network Design Lab**

   * Design multiple subnets
   * Create routing tables
   * Plan VLANs

#### Intermediate

4. **Network Monitoring Lab**

   * Monitor hosts, ports and connections
   * Detect abnormal traffic

5. **Network Segmentation Lab**

   * Separate clients/servers/security systems
   * Implement firewall rules and VLAN concepts

6. **Network Troubleshooting Lab**

   * Deliberately create DNS, routing, DHCP and connectivity problems
   * Diagnose them systematically

#### Advanced

7. **Enterprise Network Security Lab**

   * Multiple subnets
   * Routing
   * VLANs
   * Firewall
   * DMZ
   * Monitoring

#### Best projects for us

**#1 Virtual Network Lab**

→ **#2 Traffic Analysis**

→ **#5 Network Segmentation**

→ **#7 Enterprise Network**

### Our actual target

We **don't want 50 projects on our resume**.

We want roughly **8–12 progressively stronger projects**, where later projects absorb the earlier subjects.

For example, our eventual flagship project could combine:

> **Networking + Linux + Windows + Python + Web + Security + Red Team + Blue Team + Active Directory + Cloud**

That's far more valuable than having 20 tiny "projects."

And because our priority is **Red Team > Blue Team > Cloud > AppSec**, our project portfolio should eventually become deepest around:

**VAPT → AD → Red Team Lab**

while maintaining a strong parallel:

**SOC → Detection → Threat Hunting**

That gives us the breadth we wanted without losing our main specialization.
